# Trading AI public dashboard

A public GitHub Pages site showing BTCIDR market data, a locally trained logistic-regression signal, validation score, and a mountain-style price chart. The browser connects to Indodax Market Data WebSocket for live BTCIDR ticks and order-book spread. GitHub Actions refreshes model weights and validation data about every 15 minutes.

This site never publishes balances, positions, orders, exchange credentials, or local bot state. It is a public market dashboard, not an account dashboard or trading service. Signals are educational and are not a guarantee.
